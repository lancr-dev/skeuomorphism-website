# Almost Tangible | Website

A responsive, interactive showcase of **skeuomorphism web design**. The site turns familiar physical objects into a digital experience: a wooden desk, paper notebook, labeled drawers, and a metal control panel.

## Features

- Material-inspired sections with layered lighting, texture, and depth built in CSS
- Four expandable collection drawers using native HTML `<details>` elements
- Interactive shutter button, lamp switch, and studio fader
- Responsive layouts for desktop, tablet, and mobile
- Semantic HTML, keyboard-accessible controls, visible focus styles, and reduced-motion support

## Built with

HTML, CSS, and vanilla JavaScript. No framework or build step is required.
